# COL380 - Introduction to Parallel and Distributed Computing
- This repository contains the assignments undertaken and slides for 2024-25 Semester 2 offering of the course at IIT Delhi taught by Prof Subodh Kumar.
- Lab 1-3 tackle a specific HPC utility - OpenMP, MPI, CUDA. Lab 4 requires the student to design a sparse matrix multiplier by using all these utilities.
